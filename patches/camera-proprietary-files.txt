# Camera blobs for the Echo Show camera stack (cronos, crown, checkers)
#
# The paths are identical on all three devices; the blobs themselves are
# not, and must come from the device's own firmware dump. See
# scripts/device-config.sh.
#
# Reference source: Amazon/cronos/cronos:6.0/NS6573/6567:user/amz-p,release-keys
# Stock camera stack is MediaTek's legacy camera1 HAL, built for API 25
# (Android 7.1) even though the surrounding platform is Amazon's "amz-p"
# (Android 9) branch. OV9734 static metadata lives in libcam.halsensor.so.
#
# Paths are rewritten from the stock non-Treble layout (/system/vendor/lib)
# into /vendor/lib for Android 11.

# Not from the dump directly: scripts/install-private-dpframework.sh creates
# this from the stock API 25 libdpframework.so (private soname + three binary
# patches). Listed here so the ROM build ships it and install-camera.sh
# pushes it; without it the camera blobs load the ROM's Android 9
# libdpframework and crash in DpIspStream's constructor.
